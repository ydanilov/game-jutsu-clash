# Jutsu Clash 術合戦

**A cozy low-poly elemental tower defense by Diego Danylov.**

Chibi stick-man ninjas guard a floating shrine island. Build Fire, Water, Earth and Air towers along the road, power them up with gold, and drag one tower onto another to fuse a new element: Steam, Magma, Lightning, Ice, Sand, Wood, Inferno, Whirlpool, Mountain and Tempest. Every 5 waves a boss arrives. Wave 20 is the Shogun. Clear an island to unlock a new ultimate.

## Features

- 3 islands × 20 waves: Flower Meadow (easy), Sakura Hills (medium), Snow Village (hard). An island unlocks once you reach wave 10 on the one before it.
- 4 base elements, 10 fusions found by experimenting, a Fusion Codex that records your discoveries.
- 3 ultimates on a 40-second timer: Meteor (from the start), Tsunami (clear Flower Meadow), Tornado (clear Sakura Hills).
- Anime boss cut-ins for the Ronin (every 5th wave) and the Shogun (wave 20), with katakana sound effects.
- Plays with mouse, keyboard, touch or a DualShock 4. Phones play in landscape.
- Settings for music, sound, reduced motion, UI size and graphics quality. Progress is saved in the browser.

## Files

- `src.html` – the game. One file: three.js r128 (cdnjs) for the 3D world plus a 2D canvas overlay for all HUD and menus. This is exactly what gets published as the Claude artifact (no doctype/head/body).
- `index.html` – the same game wrapped in a full HTML page for Vercel. Generated by `tools/build-index.sh`. Do not edit by hand.
- `assets/` – 16:9 WebP art (1024×572): `jc_title`, `jc_meadow`, `jc_sakura`, `jc_snow`, `jc_shogun`, `jc_victory`, `jc_defeat`. Loaded by relative path. If any image fails, the game draws its own fallback.
- `tools/` – build scripts and Playwright tests.

## Testing

```bash
cd tools
npm install                 # playwright ^1.63, three@0.128.0 (offline copy for tests)
bash build-test.sh          # tools/test.html = src.html with local three.js
node boot.js                # no errors, intro renders, all 7 images load, fallback without art
node menus.js               # full menu walk-through, desktop 1440×900 + phone landscape 844×390
node run.js                 # every map, wave fast-forward, Ronin/Shogun cut-ins, win + lose
node mobile.js              # 390×844 rotate prompt, 844×390 / 768×1024 / 1024×768 fit, touch build, pinch
```

Screenshots land in `tools/shots/`. Tests drive the game through the `window.__jc` debug handle. `JC_OFFLINE=1` blocks Google Fonts.
